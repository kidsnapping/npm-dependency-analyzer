# npm-dependency-analyzer

Консольная программа для получения и визуализации графа зависимостей npm-пакетов.

## Возможности

- Получение информации о зависимостях пакетов из npm Registry.
- Построение графа прямых и транзитивных зависимостей.
- Ограничение глубины графа.
- Обработка циклических зависимостей.
- Поиск обратных зависимостей.
- Работа с тестовым графом из файла.
- Создание графа в формате DOT и изображения PNG с помощью Graphviz.

## Настройки

Настройки программы задаются в файле `config.ini`:

- `package_name` — имя пакета.
- `repository` — адрес npm Registry или путь к тестовому файлу.
- `test_mode` — режим работы (`true` или `false`).
- `version` — версия пакета.
- `max_depth` — максимальная глубина графа.

## Запуск

Для запуска необходимы JDK 17 и Graphviz.

Linux:
```bash
./run.sh
```

Windows:
```bat
run.bat
```

Параметры программы можно передать через файл конфигурации. Также можно указать имя пакета для поиска обратных зависимостей.

## Тестирование

Для запуска автоматических проверок:

```bash
./tests/run-tests.sh
```

Скрипт проверяет компиляцию программы, обработку ошибок конфигурации и создание графов для нескольких npm-пакетов.

Для тестирования необходим доступ к интернету.

## Результат работы

Программа создаёт два файла для каждого пакета:

- `.dot` — описание графа зависимостей.
- `.png` — изображение графа.

Для построения изображений используется Graphviz.
